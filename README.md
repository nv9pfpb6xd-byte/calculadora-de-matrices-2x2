Calculadora de Matrices 2x2

Descripción del Proyecto

Este proyecto consiste en el desarrollo de una aplicación de escritorio en Windows Forms utilizando el lenguaje de programación C#. La aplicación permite realizar operaciones matemáticas básicas con matrices 2x2 mediante una interfaz gráfica sencilla e interactiva.

El sistema fue desarrollado como proyecto académico para aplicar conocimientos de programación, lógica matemática y desarrollo de interfaces gráficas.

Objetivo General

Desarrollar una aplicación informática capaz de realizar operaciones básicas entre matrices 2x2, incluyendo suma, resta y multiplicación.

Explicación del Funcionamiento

El usuario debe ingresar los valores de dos matrices 2x2 en los cuadros de texto correspondientes.

Luego puede seleccionar una de las siguientes operaciones:

* Suma
* Resta
* Multiplicación

El resultado se mostrará automáticamente en la sección de resultados.

También existe un botón de limpieza que elimina todos los datos ingresados.

Validación de Datos

El sistema utiliza estructuras try-catch para evitar errores cuando el usuario introduce caracteres no numéricos.
